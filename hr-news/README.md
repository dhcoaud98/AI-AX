# HR 뉴스 MCP 서버: 매일 아침 인사 담당자의 신문

> 한 줄 요약: **도구가 신문을 가져다주고, Claude가 골라서 읽어 주고, 나는 한 줄만 남긴다.**

mcp-class 6단계 뉴스 도구를 HR 공부용으로 바꾼 버전입니다. 주제를 **노무, 채용 AI, 인사제도** 세 가지로 고정하고, 매일 읽은 것을 쌓아 가는 공부노트 기능을 더했습니다.

## 파일

| 파일 | 내용 |
|---|---|
| `server.py` | 도구 4개 + Prompt 1개 |
| `test_client.py` | 자동 테스트 (뉴스는 인터넷 필요) |
| `공부노트.md` | `save_reading`을 쓰면 생기는 나만의 기록 |

## 도구 한눈에 보기

| 이름 | 종류 | 하는 일 |
|---|---|---|
| `hr_news` | Tool | 한 주제의 최신 기사 (사전에 없는 단어도 검색) |
| `hr_briefing` | Tool | 세 주제를 한 번에, 겹치는 기사는 한 번만 |
| `save_reading` | Tool | 기억할 기사를 공부노트에 "나에게 무슨 의미인지"와 함께 저장 |
| `list_readings` | Tool | 최근 N일 공부 기록 보기 (주간 복습용) |
| `daily_hr_reading` | Prompt | 매일 아침 10분 읽기 루틴 양식 |

주제별 검색어는 `TOPICS`에 있습니다. `OR`로 비슷한 말을 묶어 두었고, 한 줄만 추가하면 주제가 늘어납니다.

```python
TOPICS = {
    "노무": "근로기준법 OR 노무 OR 고용노동부 OR 노동법",
    "채용 AI": "AI 채용 OR AI 면접 OR 채용 인공지능",
    "인사제도": "인사제도 OR 성과평가 OR 보상제도 OR 직무급",
}
```

## 매일 쓰는 법 (10분 루틴)

1. Claude Desktop 입력창의 도구 메뉴에서 **`daily_hr_reading`** 양식을 고릅니다.
2. Claude가 `hr_briefing`으로 기사를 가져와 주제별로 1개씩 골라 줍니다. 각 기사마다 쉬운 요약, 중요한 이유, "우리 회사라면?" 질문이 붙습니다.
3. 마음에 드는 것 하나를 저장합니다. 이때 **요약이 아니라 내 생각**을 한 줄 적는 게 포인트입니다.
4. 금요일에는 "이번 주 공부노트 보고 정리해 줘" → `list_readings`로 한 주를 돌아봅니다.

양식을 안 써도 됩니다. "오늘 HR 뉴스 브리핑해 줘", "요즘 육아휴직 관련 뉴스 뭐 있어?"처럼 그냥 물어봐도 됩니다.

## 6단계 원본과 달라진 점

| | 6단계 `latest_news` | HR 뉴스 서버 |
|---|---|---|
| 주제 | 고정 RSS 3개 + 검색 | 세 HR 주제를 검색어 묶음으로 |
| 기간 | 지정 없음 | `when:Nd`로 최근 N일만 |
| 한 번에 보기 | 주제별로 따로 | `hr_briefing`으로 세 주제를 한 번에 |
| 기록 | 없음 | 공부노트에 쌓기 |
| 실패 처리 | 전체 실패 | 한 주제가 실패해도 나머지는 계속 |

## 알아 둘 점

- 도구는 **제목과 링크만** 가져옵니다. Claude의 요약은 제목을 바탕으로 한 것이니, 법 개정이나 시행일처럼 중요한 내용은 반드시 원문 링크로 확인하세요. 양식에도 "추측하지 말고 원문 확인 필요라고 적으라"는 지시를 넣어 두었습니다.
- MCP 도구는 **물어볼 때 가져오는 가판대**입니다. 매일 아침 알아서 받고 싶다면 Claude 예약 작업(배달)을 함께 쓰면 됩니다.
