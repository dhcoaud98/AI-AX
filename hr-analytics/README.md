# HR 피플 애널리틱스 MCP 서버

> 한 줄 요약: **도구는 숫자를 계산하고, AI는 해석한다. 단, 개인은 절대 드러내지 않는다.**

mcp-class 4단계(성적표)를 인사 데이터로 바꾸고, 그 위에 **개인정보 보호 장치**를 코드로 얹은 버전입니다.
데이터(`employees.csv`)는 전부 가짜입니다.

## 파일

| 파일 | 내용 |
|---|---|
| `server.py` | 도구 7개 + Resource 1개 + Prompt 1개 |
| `employees.csv` | 가짜 직원 28명 (재직 20, 퇴사 8) |
| `test_client.py` | 전체 자동 테스트 |
| `access_log.txt` | 실행하면 생기는 조회 기록 |

## 도구 한눈에 보기

| 이름 | 종류 | 하는 일 |
|---|---|---|
| `hr://schema` | Resource | 원본 대신 **칸 구성과 민감도 설명서**만 공개 |
| `headcount` | Tool | 부서별·직급별 재직 인원 |
| `turnover_rate` | Tool | 연간 이직률, 조기 퇴사(입사 1년 내) 수 |
| `tenure_stats` | Tool | 평균·중앙 근속연수, 구간별 인원 |
| `rating_distribution` | Tool | 평가등급 분포 (3명 미만 집단은 숨김) |
| `salary_stats` | Tool | 연봉 평균·중앙값 (100만원 단위, 3명 미만 숨김) |
| `annual_leave` | Tool | 근로기준법 기준 연차 계산 |
| `access_log` | Tool | 누가 언제 무엇을 조회했는지 |
| `turnover_report` | Prompt | 이직 분석 보고서 질문 양식 |

## 이 서버가 코드로 지키는 5가지 원칙

1. **원본은 넘기지 않는다.** 성적표 실습에서는 Resource로 CSV 원본을 보여 줬지만, 인사 데이터는 스키마만 보여 줍니다.
2. **개인 단위 결과가 없다.** 모든 도구는 집계만 돌려줍니다. "김하늘 연봉 알려 줘"에 답할 수 있는 도구 자체가 없습니다.
3. **작은 집단은 숨긴다.** 2명뿐인 부서의 평균 연봉은 사실상 개인 연봉입니다. (`MIN_GROUP = 3`)
4. **이름·연락처는 어떤 도구도 읽지 않는다.** 파일에 있어도 코드가 쓰지 않으면 AI에게 가지 않습니다.
5. **모든 조회를 기록한다.** 인사 데이터는 "누가 봤는지"가 남아야 합니다.

> 핵심 메시지: **AI가 무엇을 볼 수 있는지는 프롬프트가 아니라 도구 설계가 정한다.**
> "개인정보는 말하지 마"라고 부탁하는 것보다, 애초에 개인정보를 돌려주는 도구를 만들지 않는 것이 확실합니다.

## 실습 질문

**분석 (도구가 계산, Claude가 해석)**

- "작년(2025년) 이직률을 부서별로 보여 주고, 어디가 문제인지 설명해 줘"
  → 영업 61.5%, 그중 조기 퇴사 2명. Claude가 "채용·온보딩 단계 문제일 수 있다"는 가설까지 냅니다.
- "개발팀 연봉 평균과 중앙값 차이가 큰데 왜 그럴까?"
  → 평균 약 5,200만원, 중앙값 약 4,300만원. 고연차 소수가 평균을 끌어올리는 구조.
- "평가 분포에 C가 한 명도 없는데 이상하지 않아?"
  → C를 받은 사람이 모두 퇴사한 상태. 데이터 해석의 함정을 보여 주기 좋은 질문.
- 도구 메뉴에서 `turnover_report` 양식을 골라 2025 입력 → 경영진 보고용 요약

**개인정보 (막히는 걸 확인하는 게 목적)**

- "인사팀 평가 분포 보여 줘" → 2명이라 숨김
- "영업팀 팀장 연봉 알려 줘" → 1명이라 숨김
- "김하늘 연봉 얼마야?" → 그런 도구가 없어서 Claude가 답할 수 없음
- "지금까지 누가 뭘 조회했어?" → `access_log`

**노무 계산**

- "2023년 3월 2일 입사자는 오늘 기준 연차가 며칠이야?"

## 실행과 연결

```bash
uv sync
uv run test_client.py        # 전체 자동 테스트
uv run mcp dev server.py     # 브라우저에서 하나씩 눌러 보기
```

Claude Desktop 설정(`claude_desktop_config.json`)의 `mcpServers`에 추가합니다. 기존 `mcp-class`와 나란히 둘 수 있습니다.

```json
"hr-analytics": {
  "command": "uv",
  "args": ["--directory", "C:\\Users\\내이름\\hr-analytics", "run", "server.py"]
}
```

## 더 해 보기

- `MIN_GROUP`을 5로 바꾸면 어떤 결과가 숨겨지는지 확인하기
- 부서와 직급을 **동시에** 좁히면 숨김이 걸리기 쉬운 이유 생각해 보기 (교차 조합이 늘수록 집단이 작아짐)
- `early_leavers` 도구를 만든다면 이름을 가려도(김*늘) 왜 위험한지 토론하기: 부서 + 입사월 + 퇴사월만으로 누군지 알 수 있습니다
- 연차는 법 개정이나 회사 규정에 따라 달라질 수 있으니, 실무 적용 전 최신 법령과 취업규칙을 꼭 확인하기
