# MCP 입문 강의안: AI에게 여섯 가지 능력 달아 주기

> 대상: MCP를 처음 접하는 사람 (Python 기초만 있으면 충분)
> 소요 시간: 약 100분 (짧게 할 때는 1단계와 3단계만 진행해도 30분 안에 가능)
> 준비물: `server.py`, `students.csv`, `pyproject.toml`, `test_client.py`

---

## 1. 강의 목표

수업이 끝나면 참가자는 다음을 할 수 있습니다.

1. MCP가 무엇이고 왜 필요한지 **한 문장으로 설명**한다.
2. Python 함수에 데코레이터를 붙여 **MCP 도구를 직접 만든다**.
3. 만든 서버를 **Claude Desktop에 연결**하고 동작을 확인한다.
4. Tool과 Resource의 차이, **허용 버튼과 보안**의 의미를 이해한다.
5. **도구는 가져오고, AI는 해석한다**는 역할 분담을 이해한다.

## 2. 핵심 개념 (도입 10분)

### 한 문장 정의

> **MCP는 AI에게 도구를 쥐여 주는 표준 연결 방식입니다.**
> USB-C처럼 한 번 만들면 Claude Desktop, Claude Code, Cursor 등 여러 AI 앱에서 그대로 쓸 수 있습니다.

### 그림으로 설명하기

```
[Claude Desktop]  ⇄  MCP (공통 규격)  ⇄  [내가 만든 서버]  →  시계, 파일, 인터넷 ...
     "머리"                                   "손과 눈"
```

- AI는 **똑똑한 머리**지만, 혼자서는 시계도 못 보고, 내 파일도 못 열고, 인터넷도 못 봅니다.
- MCP 서버는 AI에게 **손과 눈**을 달아 줍니다.
- 무엇을 할지는 AI가 판단하고, **실제 실행은 내 컴퓨터의 내 코드**가 합니다.

### MCP 서버가 제공하는 세 가지

| 종류 | 비유 | 예시 |
|---|---|---|
| **Tool** | AI가 쓰는 도구 (실행) | 시계 보기, 메모 저장 |
| **Resource** | AI가 읽는 자료 (참고) | 성적표 파일 |
| **Prompt** | 미리 만든 질문 양식 | "이 코드를 리뷰해 줘" |

## 4. 단계별 실습

각 단계는 같은 흐름으로 진행합니다.

> **① 연결 전 질문 → ② 코드 보기 → ③ 연결 후 질문 → ④ 한 줄 정리**

연결 전 질문은 서버를 연결하지 않은 Claude(웹 claude.ai 등)에 해 보면 차이가 잘 보입니다.

---

### 1단계 ⏰ 시계: "AI한테 시계를 달아 준 거예요" (15분)

**배우는 것:** Tool의 기본 구조 (데코레이터, 타입 힌트, docstring)

**① 연결 전:** "오늘 무슨 요일이야? 수능까지 며칠 남았어?"
→ Claude가 정확한 날짜를 모르거나 추측으로 답합니다.

**② 코드:**

```python
@mcp.tool()
def now() -> str:
    """현재 날짜, 요일, 시간을 알려줍니다."""
    t = datetime.now()
    return f"{t:%Y-%m-%d %H:%M}"

@mcp.tool()
def d_day(target: str) -> str:
    """목표 날짜(YYYY-MM-DD 형식)까지 며칠 남았는지 계산합니다."""
    days = (date.fromisoformat(target) - date.today()).days
    return f"D-{days}"
```

**설명 포인트**

- `@mcp.tool()` 한 줄이면 평범한 함수가 AI의 도구가 됩니다.
- `target: str` 같은 **타입 힌트**는 "이 도구는 이런 값을 받아요"라는 설명서가 됩니다.
- `"""docstring"""`은 **Claude가 읽는 사용 설명서**입니다. Claude는 이걸 보고 언제 이 도구를 쓸지 정합니다.

**③ 연결 후:** 같은 질문 → `now`, `d_day` 도구가 호출되고 정확한 답이 나옵니다.

**④ 한 줄 정리:** AI는 지금이 언제인지 모른다. 도구가 알려 준다.

---

### 2단계 🎲 주사위: "AI한테 진짜 주사위를 쥐여 준 거예요" (10분)

**배우는 것:** 입력값과 기본값, 리스트 입력

**① 연결 전:** "주사위 3개 굴려 줘" → 그럴듯한 숫자를 지어냅니다. (진짜 무작위가 아님)

**② 코드:**

```python
@mcp.tool()
def roll_dice(sides: int = 6, count: int = 1) -> list[int]:
    """주사위를 굴립니다. sides: 면의 수(기본 6), count: 굴릴 개수(기본 1)."""
    return [random.randint(1, sides) for _ in range(count)]

@mcp.tool()
def pick_one(items: list[str]) -> str:
    """목록에서 하나를 무작위로 뽑습니다."""
    return random.choice(items)
```

**③ 연결 후:** "발표 순서 정하게 김하늘, 이바다, 박구름 중 한 명 뽑아 줘"

**④ 한 줄 정리:** AI는 숫자를 '지어내고', 도구는 실제로 '뽑는다'.

---

### 3단계 📝 메모장: "AI한테 수첩을 준 거예요" (15분)

**배우는 것:** 쓰기 도구, 허용 버튼, 안전 교육

**① 연결 전:** 채팅 A에서 "내일 우산 챙기라고 기억해 줘" → **새 채팅 B**에서 "내가 뭐 기억해 달라고 했지?" → 모릅니다.

**② 코드:**

```python
@mcp.tool()
def save_note(text: str) -> str:
    """메모를 파일에 저장합니다."""
    with NOTES_FILE.open("a", encoding="utf-8") as f:
        f.write(text + "\n")
    return f"저장했어요: {text}"

@mcp.tool()
def list_notes() -> str:
    """저장된 메모 전체를 보여줍니다."""
    return NOTES_FILE.read_text(encoding="utf-8")
```

**③ 연결 후:** 같은 시나리오 → 새 채팅에서도 메모가 나옵니다. 실습 폴더에 `notes.txt` 파일이 생긴 것도 함께 확인합니다.

**설명 포인트: 허용 버튼과 보안 (중요)**

- 도구를 쓰기 전에 Claude Desktop이 **"허용할까요?"**라고 묻습니다.
- MCP 서버는 **내 컴퓨터 권한으로 실행되는 프로그램**입니다. 저장은 되지만 삭제나 전송도 될 수 있다는 뜻입니다.
- 그래서 **직접 만들었거나 믿을 수 있는 서버만** 연결하고, 되돌릴 수 없는 작업은 "항상 허용"을 피합니다.

**④ 한 줄 정리:** AI는 대화가 끝나면 잊는다. 파일에 쓰면 남는다. 단, 쓰기는 신중하게.

### 4단계 📊 성적표: "AI한테 우리 반 서랍 열쇠를 준 거예요" (15분)

**배우는 것:** Resource와 Tool의 차이, 내 데이터 다루기

**① 연결 전:** "우리 반 수학 평균 알려 줘" → 데이터가 없어서 답할 수 없습니다.

**② 코드:**

```python
@mcp.resource("students://all")
def all_students() -> str:
    """우리 반 성적표 원본(CSV)."""
    return STUDENTS_FILE.read_text(encoding="utf-8")

@mcp.tool()
def subject_average(subject: str) -> str:
    """과목(국어/영어/수학)의 반 평균 점수를 계산합니다."""
    ...
```

**설명 포인트**

| | Resource | Tool |
|---|---|---|
| 비유 | 책상 위에 펼쳐 둔 자료 | 손에 쥔 계산기 |
| 하는 일 | 읽기만 | 실행, 계산 |
| 예 | 성적표 원본 | 평균 계산, 조건 검색 |

- 실습에는 **가짜 데이터**(`students.csv`)를 씁니다. 실제 개인정보는 사용하지 않습니다.

**③ 연결 후:** "수학 평균은?", "영어 90점 이상인 학생은?"
→ 정답: 수학 평균 84.4점, 영어 90점 이상은 이바다·최별 (정확히 계산되는지 직접 확인)

**④ 한 줄 정리:** AI는 내 컴퓨터 파일을 모른다. 도구로 열어 줄 수 있다.

---

### 5단계 🌤 날씨: "AI한테 인터넷 창문을 열어 준 거예요" (10분)

**배우는 것:** 외부 API 호출, 에러 처리

**① 연결 전:** "지금 서울 날씨 어때?" → 실시간 정보를 모릅니다.

**② 코드 흐름:**

```
도시 이름 → (Open-Meteo 지오코딩) → 위도/경도 → (Open-Meteo 날씨) → "서울: 맑음, 18°C"
```

- Open-Meteo는 **무료이고 API 키가 필요 없어** 교육용으로 좋습니다.
- 인터넷이 끊겨도 서버가 죽지 않도록 `try/except`로 **이유를 문장으로 돌려줍니다**. 그러면 Claude가 사용자에게 상황을 설명할 수 있습니다.

**③ 연결 후:** "지금 서울 날씨 어때? 우산 챙겨야 해?"
→ `weather` 도구 결과를 보고 Claude가 우산이 필요한지까지 판단해 줍니다.

**④ 한 줄 정리:** AI는 지금 바깥 세상을 모른다. 도구가 창문을 열어 준다.

### 6단계 📰 뉴스: "AI한테 신문을 쥐여 준 거예요" (10분)

**배우는 것:** RSS 읽기, **도구는 가져오고 AI는 해석한다**는 역할 분담

**① 연결 전:** "GitHub에 이번 주 새로 나온 기능 뭐 있어?", "요즘 기업교육 쪽 뉴스 뭐 있어?"
→ 최신 소식을 모르거나, 오래된 정보로 그럴듯하게 답합니다.

**RSS란?**
웹페이지는 사람이 보라고 만든 화면이라 메뉴, 광고 같은 잡음이 많습니다. **RSS는 사이트가 "새 글 목록만" 깔끔하게 정리해 공개한 파일**입니다. 날씨처럼 무료이고 API 키도 필요 없습니다.

```
일반 웹페이지:  [메뉴][광고][배너] 새 글 제목 [광고][푸터] ...   ← 사람용
RSS 파일:      제목1, 링크1 / 제목2, 링크2 / 제목3, 링크3       ← 기계용
```

**② 코드:**

```python
NEWS_FEEDS = {
    "AI": "https://huggingface.co/blog/feed.xml",     # Hugging Face 블로그
    "개발": "https://github.blog/changelog/feed/",     # GitHub 새 기능
    "AX": "https://blogs.nvidia.com/feed/",            # NVIDIA 블로그
}

@mcp.tool()
def latest_news(topic: str, count: int = 5) -> str:
    """관심 분야의 최신 글 제목, 날짜, 링크를 가져옵니다. 새 소식이나 최근 뉴스를 물으면 사용하세요.
    topic: AI, 개발, AX 중 하나. 그 밖의 단어는 구글 뉴스에서 검색합니다."""
    url = NEWS_FEEDS.get(topic) or _google_news_url(topic)
    try:
        lines = _read_feed(url, count)
    except (OSError, ET.ParseError) as e:
        return f"'{topic}' 뉴스를 가져오지 못했어요 ({e})."
    return "\n".join(lines)
```

**설명 포인트**

- `NEWS_FEEDS`는 4단계 성적표의 과목 목록과 같은 역할입니다. **주소 한 줄만 추가하면** 볼 사이트가 늘어납니다.
- 사전에 없는 단어(예: "기업교육", "팀스파르타")는 **구글 뉴스 검색 RSS**로 찾습니다. 그래서 어떤 키워드든 물어볼 수 있습니다.
- 5단계 날씨와 같은 `try/except` 구조입니다. **같은 패턴을 다시 써 보는 것**이 이 단계의 복습 포인트입니다.
- 가장 중요한 것: 도구는 **제목과 링크만** 가져옵니다. 고르고, 요약하고, "나한테 무슨 의미인지" 설명하는 건 Claude가 합니다.

```
나: "기업교육 뉴스 중에 우리 팀이 알아야 할 거 골라 줘"
  ↓
Claude: "최신 소식은 모르니 latest_news를 쓰자"     ← 머리 (판단)
  ↓
내 서버: 구글 뉴스 RSS에서 제목 5개를 가져옴         ← 손 (가져오기)
  ↓
Claude: 5개 중 중요한 2개를 골라 쉽게 설명           ← 머리 (해석)
```

**③ 연결 후:** "GitHub에 이번 주 새로 나온 거 3개만 알려 줘", "기업교육 뉴스 중에 HR 담당자가 알아야 할 거 골라서 설명해 줘"
→ `latest_news` 도구가 호출되고, 실제 최신 글 목록을 바탕으로 Claude가 골라서 해설합니다.

**④ 한 줄 정리:** AI는 오늘 나온 소식을 모른다. 도구가 신문을 가져다주고, AI가 읽어 준다.

**더 해 보기 (선택)**

- `NEWS_FEEDS`에 자주 보는 사이트의 RSS 주소를 추가해 보기 (사이트 하단의 RSS 아이콘이나 `/feed`, `/rss` 주소)
- 매일 아침 자동으로 받고 싶다면 → MCP 도구(물어볼 때 가져오는 **가판대**)와 달리 Claude 예약 작업(알아서 보내 주는 **배달**)을 쓰면 됩니다.

## 5. Claude Desktop에 연결하기 (10분)

1. Claude Desktop → **설정 → 개발자 → 설정 편집**
2. `claude_desktop_config.json`에 아래 내용을 넣습니다. **경로는 반드시 절대경로로** 씁니다.

```json
{
  "mcpServers": {
    "mcp-class": {
      "command": "uv",
      "args": ["--directory", "C:\\Users\\내이름\\mcp-class", "run", "server.py"]
    }
  }
}
```

Mac은 경로만 `"/Users/내이름/mcp-class"` 형태로 바꿉니다.

3. Claude Desktop을 **완전히 종료**(트레이 아이콘까지)한 뒤 다시 실행합니다.
4. 입력창 아래 도구 메뉴에 `mcp-class`가 보이면 성공입니다.

**연결 전에 미리 테스트하는 방법**

```bash
uv run mcp dev server.py      # 브라우저에서 도구를 하나씩 눌러 보기 (MCP Inspector)
uv run test_client.py         # 10개 도구를 한 번에 자동 테스트
```

## 7. 막혔을 때 체크리스트

| 증상 | 원인과 해결 |
|---|---|
| Claude에 도구가 안 보임 | 앱을 완전히 종료하지 않았거나 경로가 상대경로입니다. |
| 연결되자마자 끊김 | 코드에 `print()`가 있습니다. stdout은 Claude와 대화하는 통로이므로 로그는 `print(..., file=sys.stderr)`로 씁니다. |
| `No module named mcp.server.fastmcp` | mcp 2.x에서는 `MCPServer`로 이름이 바뀌었습니다. 제공된 코드는 두 버전 모두 동작합니다. |
| `uv`를 찾을 수 없음 | config의 `command`에 uv 전체 경로를 넣습니다. (`where uv` 또는 `which uv`로 확인) |
| 날씨만 실패 | 인터넷 연결이나 회사 방화벽을 확인합니다. |
| 뉴스만 실패 (`403`, `Forbidden`) | 그 사이트가 프로그램 접속을 막은 것입니다. 다른 RSS 주소로 바꾸거나 구글 뉴스 검색(사전에 없는 단어)으로 대신합니다. |
| 뉴스가 "가져오지 못했어요 (syntax error…)" | RSS 주소가 아니라 일반 웹페이지 주소를 넣은 경우입니다. 사이트의 RSS 주소(`/feed`, `/rss`, `feed.xml`)를 다시 확인합니다. |

## 8. 마무리 퀴즈 (5분)

1. MCP를 한 문장으로 설명해 보세요.
   → AI에게 도구를 쥐여 주는 표준 연결 방식
2. Claude가 도구를 언제 쓸지 판단할 때 무엇을 읽나요?
   → 함수의 이름과 docstring
3. 1000을 더하는 `add` 도구를 연결하면, 웹 claude.ai에서도 1000이 더해질까요?
   → 아니요. 서버를 등록한 그 컴퓨터의 Claude Desktop에서만 해당됩니다.
4. 남이 만든 MCP 서버를 함부로 설치하면 안 되는 이유는?
   → 내 컴퓨터 권한으로 실행되는 프로그램이기 때문
5. Tool과 Resource의 차이는?
   → Tool은 실행(계산기), Resource는 읽기(펼쳐 둔 자료)
6. `latest_news` 도구는 뉴스 제목만 돌려주는데, Claude가 요약과 해설까지 해 주는 이유는?
   → 도구는 정보를 '가져오고', 판단과 해석은 AI가 하는 역할 분담이기 때문
