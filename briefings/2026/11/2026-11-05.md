## 🤖 AI·개발

### 1. CrowdStrike, 말 안 듣는 AI 에이전트를 끄는 'AI 킬 스위치' 출시…Claude Code·Copilot 안에서도 규칙 강제 (11/3)
보안 회사 CrowdStrike가 에이전트 보안 제품 Falcon Guardian에 'AI 킬 스위치'를 넣었습니다. 권한 있는 관리자가 문제 에이전트의 실행을 멈추고, 같은 PC·PC 그룹에서 다시 켜지지 못하게 막고, 회사 네트워크 접속을 끊을 수 있으며 모든 조치는 감사 기록에 남습니다. 함께 공개한 'Agent-Level Hooks'는 Claude Code, OpenAI Codex, GitHub Copilot, Microsoft 365 Copilot, Cursor 안에서 회사 정책을 강제하고 프롬프트를 검사합니다. 악성 스킬·MCP 서버를 들어오기 전에 찾아내는 기능도 포함됐습니다. 다만 실행 중단은 우선 게이트웨이(네트워크 길목)에서 이뤄지고, PC에서 직접 끄는 기능은 "곧" 나온다고만 밝혔습니다.
- **→ 나에게 의미:** 11/4에 다룬 'Postman 무단 연결' 같은 사고에 대해, 보안 업계가 **"감시"를 넘어 "즉시 정지"를 제품으로 팔기 시작**했습니다. 에이전트 교육의 안전 파트에 "우리 회사는 누가, 어떤 기준으로 에이전트를 멈추는가(정지 권한·절차)"를 한 장으로 정리해 넣으면 보안 부서 승인을 받기 쉬워집니다.

### 2. OpenAI, 코드 저장 스타트업 Pierre Computer 인수…Codex 에이전트가 쏟아내는 코드를 담을 '전용 창고' 마련 (11/4 보도)
OpenAI가 Git 기반 코드 저장 서비스 'Code Storage'를 만든 Pierre Computer를 인수해 Codex에 직접 붙인다고 Axios가 전했습니다(인수 조건 비공개). 이틀 전 OpenAI는 자체 Git 백엔드 'Pando'를 공개하며 코드 업로드(push) 지연을 약 80% 줄였고 하루 1페타바이트 가까운 데이터를 처리한다고 밝혔습니다. 사람이 아니라 **에이전트가 코드를 올리는 양이 폭증**해 기존 저장소 인프라로는 버티기 어려워졌다는 뜻으로 읽힙니다. Axios 원문은 직접 확인하지 못했고 AI 뉴스 집계 사이트를 통해 확인한 내용입니다.
- **→ 나에게 의미:** 코딩 에이전트가 '시범'을 넘어 인프라를 새로 지어야 할 만큼 쓰이고 있다는 신호입니다. 개발 조직 대상 교육을 기획할 때 "에이전트가 만든 코드를 누가 어떻게 검토·병합하는가"(리뷰 책임) 실습 비중을 늘려 볼 만합니다.
- 출처: [AI Weekly – OpenAI Buys Pierre Computer, Folds Code Storage Into Codex](https://aiweekly.co/alerts/openai-buys-pierre-computer-folds-code-storage-into-codex) · [Axios – OpenAI Acquires Pierre Computer to Build a Dedicated Git Backend Into Codex](https://www.axios.com/2026/11/04/openai-pierre-computer-github)

## 🏢 AX 기업

### 3. 현대제철, 생성형 AI 통합 플랫폼 'Steel-X' 가동…직원이 코딩 없이 업무 챗봇·에이전트를 만들어 공유 (11/4)
현대제철이 현대오토에버와 함께 기획 단계부터 만든 생성형 AI 플랫폼 'Steel-X'를 열었습니다. 여러 시스템과 Teams 등에 흩어진 사내 문서를 AI가 읽을 수 있는 형태로 자동 변환해 모으고, 사내 구축형 AI와 외부 AI 서비스 중 업무에 맞는 것을 골라 쓰게 했습니다. 'AI 플레이그라운드'에서는 개발 지식 없이 개인·팀 자료로 업무 전용 챗봇과 에이전트를 만들어 개인·조직·전사 단위로 공유할 수 있습니다. 규정·매뉴얼 검색, 기술 문서 요약, 설비 이력 분석 등이 첫 활용처이며, 정량 효과 수치는 공개되지 않았습니다.
- **→ 나에게 의미:** 제조 대기업의 AX가 **'지식 모으기 → 직원이 직접 에이전트 만들기 → 공유'** 순서로 굴러가고 있습니다. 사내 플랫폼이 생기면 교육의 핵심은 툴 사용법보다 "내 팀 자료로 쓸 만한 에이전트를 만들고 남에게 공유할 수준으로 다듬기"가 되니, 실습 과제를 '공유까지 마치기'로 잡아 보세요.
- 출처: [아시아경제 – 현대제철, 생성형 AI 플랫폼 가동…전사 AX 가속화](https://www.asiae.co.kr/article/2026110408460448757)

### 4. 삼성SDS는 구미에, LG CNS는 자카르타에…IT서비스 기업이 'AI 데이터센터 사업자'로 (11/2, 11/3 보도)
삼성SDS가 11/2 경북 구미에서 AI 전용 데이터센터 착공식을 열었습니다. 초기 60MW, 수요에 따라 최대 120MW까지 늘릴 수 있는 규모로 2028년 말 준공 목표이며, 삼성 관계사의 제조·로봇 AI 전환과 로봇 학습 데이터 처리를 지원하고 GPU 연산 자원을 다른 기업에 빌려주는 사업도 키웁니다. 같은 날 LG CNS는 인도네시아 자카르타에 30MW 규모 AI 데이터센터를 완공했는데, 국내 기업이 해외 고객의 AI 데이터센터를 현지에 직접 지은 첫 사례이며 완공 전에 수용 용량 전부를 채울 고객을 확보했습니다.
- **→ 나에게 의미:** 11/3에 다룬 "AI 붙이기 전 정리 수요"에 이어, 국내 IT서비스 기업들이 **'시스템 구축'에서 'AI가 돌아갈 기반(전력·GPU) 공급'으로** 사업 축을 옮기고 있습니다. 그룹사·고객사 교육 자료에서 "우리 AI는 어디서 돌아가는가(사내 구축 vs 외부 클라우드)"를 설명할 때 좋은 국내 사례가 됩니다.
- 출처: [서울경제TV – 'SI에서 AI 인프라 사업자로'…삼성·LG, 국내외 공략](https://www.sentv.co.kr/article/view/sentv202611030125)

## 🎓 기업교육

### 5. 패스트캠퍼스 운영사 데이원컴퍼니, 'DAY1 AX' 출범…140명 조직으로 AI 구축과 교육을 한 번에 (11/3)
데이원컴퍼니가 8월 인수한 AX 구축 전문기업 스페이스와이와 기존 기업교육 부문을 합쳐 약 140명 규모의 기업 AX 통합 브랜드 'DAY1 AX'를 내놓았습니다. 업무별 AI 전환 수준 진단(AX Scan), 데이터·시스템 정비(AX Ready), 임원 해커톤, 실무자가 에이전트를 직접 설계하는 캠프, 사내 FDE(현장 배치 엔지니어) 육성, 업무 흐름·역할·평가 기준을 다시 짜는 'AI-Native Team' 과정으로 구성됩니다. 기술 전문가가 시스템을 만들고 교육 전문가가 현업 운영을 도와, 프로젝트가 끝난 뒤에도 회사가 스스로 운영하게 하겠다는 구상입니다.
- **→ 나에게 의미:** 11/1 팀스파르타, 11/3 에듀윌에 이어 **패스트캠퍼스 진영도 '교육 + 구축' 패키지**로 왔습니다. 외부 업체 비교 시 "교육 후 실제 에이전트 구축까지 누가 책임지는지", "'사내 FDE 육성'처럼 우리 직원이 스스로 운영하게 만드는 과정이 있는지"를 체크 항목으로 넣어 보세요.
- 출처: [유니콘팩토리 – 데이원컴퍼니, 기업 AX 통합 브랜드 출범…구축·교육 일원화 지원](https://www.unicornfactory.co.kr/article/2026110310022899300)

### 6. 에이블런, HRD 담당자용 'AI 에이전트 교육 처방전' 공개…도입 전·중·후 15가지 점검 기준 (11/4)
AI 교육 기업 에이블런이 에이전트 교육을 검토 중인 기업·기관 9곳을 인터뷰해, HRD 담당자가 확인할 15가지 기준을 5개 영역(교육 대상, 보안 환경, 교육 시간, 결과물 수준, 업체 선정)으로 정리한 가이드북을 냈습니다. 교육 전에는 망분리·보안 정책 때문에 현업에서 못 쓰는 도구가 아닌지 먼저 확인하고, 교육 중에는 결과물 목표(시제품인지 실제 업무 투입인지)를 합의해 샘플 데이터로 검증하며, 교육 후에는 시범 적용부터 실운영까지 지원 일정과 절차를 미리 정하라는 내용입니다. 가이드북은 에이블런 홈페이지에서 받을 수 있으며, 업체 홍보 성격이 있는 자료입니다.
- **→ 나에게 의미:** "교육 때 쓴 도구를 회사에선 못 쓴다"는 흔한 실패를 막는 체크리스트라 **에이전트 교육 기안서의 사전 점검표**로 바로 쓸 만합니다. 특히 '결과물 목표 수준 합의'는 5번 DAY1 AX 같은 업체 제안서를 비교할 때도 기준이 됩니다.
