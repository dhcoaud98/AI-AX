# AI-AX 

**git 로컬 환경 연결하기 ​​** 

**로컬 :arrow_forward: 원격 올리기** (로컬 환경에 git 설정 + 저장소 연결 완료 후)

1. ```bash
   git add . 
   or
   git add {파일명}
   ```

2. ```bash
   # 로그와 상태 확인
   
   git log
   git status
   ```

3. ```bash
   # 로컬 저장소에 변경사항 커밋하기
   
   git commit -m "first-commit"
   ```

4. ```bash
   # 원격 저장소에 푸쉬하기
   
   git push 
   ```
